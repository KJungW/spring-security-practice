# 스프링 시큐리티 실습

### 학습 내용

- 들어가며
    - 스프링 시큐리티란?
    - 기본적인 동작 방식
- 인증
    - FORM 기반 인증
    - JWT 토큰 기반 인증
    - OAuth 2.0 기반 인증
- 인가
    - 두가지 레벨의 인가 방식
- 인가/인증 결과 핸들링
    - 인증 실패 핸들링
    - 웹 레벨의 인가 실패 힌들링
    - 메서드 레벨의 안가 실패 핸들링
    - 로그인 성공 핸들링
    - 로그인 실패 핸들링
- 그외
    - 필터 체인에 대한 각종 설정
    - 시큐리티와 REST DOCS 통합
